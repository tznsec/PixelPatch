# Pixel Patch: Garage Days

Strona projektu i buildy testowe pierwszej wersji gry.

- **Strona (GitHub Pages):** https://tznsec.github.io/pixelpatch/
- **Build PC:** https://github.com/tznsec/pixelpatch/releases/latest/download/PixelPatch.exe
- **Android (APK):** https://github.com/tznsec/pixelpatch/releases/latest/download/PixelPatch.apk

## O projekcie

Pixel Patch to pixel-artowy symulator serwisu komputerowego. **Garage Days** to nazwa pierwszej pełnej wersji, nad którą pracujemy przez rok — od dnia 1 do premiery na Steam.

Strona zawiera:

- intro z V0idVexem (TZNsec) i kormeliuszkiem (K2STUDIO),
- odliczanie do premiery (25.10.2027),
- plan roku Q1–Q4,
- galerię zrzutów z builda,
- linki do buildów testowych.

## Struktura

```
index.html      # strona
styles.css      # styl
script.js       # intro, odliczanie, galeria
assets/         # logo + zrzuty z gry
```

Strona jest statyczna, bez zewnętrznych zależności — działa też offline z pliku.

## Buildy

Pliki `.exe` i `.apk` są za duże na zwykły commit (limit 100 MB na plik w Git), dlatego są dodane jako **assety wydania GitHub Releases**. Linki w stopce i w sekcji Steam prowadzą do najnowszego wydania.
